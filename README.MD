# P1 · 单景 NDVI 可复现链路（云南）

## 1. 目标

用一景 Landsat 8 影像，跑通「下载 → 波段 → NDVI → 掩膜裁剪 → 出图」全流程，步骤可被他人复现。

## 2. 数据

- 来源：地理空间数据云 gscloud.cn
- 数据集：Landsat 8 OLI_TIRS（L1TP）
- 日期：2026-_01_-_16_ ｜ 轨道号：___131_/_042___
- 使用波段：B4（红）、B5（近红）、MTL（元数据）
- 选取理由：云量 __0.07__%（同期最低）

## 3. 处理步骤

1. gscloud 检索（区域=云南，时间=2021 年干季，云量<20%），整包下载、解压至 01_raw\
2. ArcGIS Pro 加载 B4、B5，图层重命名为 B4、B5
3. 栅格计算器计算 NDVI → 输出 04_ndvi\ndvi_full.tif
   - 表达式：(Float("B5") - Float("B4")) / (Float("B5") + Float("B4") + 0.000001)
4. 按掩膜提取：输入=ndvi_full，掩膜=yunnan.shp（云南省面）→ 输出 04_ndvi\ndvi_yunnan.tif
5. 符号化：拉伸 + 红-黄-绿配色
6. 布局：图例 + 比例尺 + 指北针 + 标题 → 导出 300 DPI → 05_fig\ndvi_yunnan_2026_0116.png

## 4. 产出文件

- 04_ndvi\ndvi_full.tif —— 整景 NDVI（−0.31 ~ 0.93）
- 04_ndvi\ndvi_yunnan.tif —— 截取到云南部分
- 05_fig\ndvi_yunnan_2026_0116.png —— 成图（300 DPI）

## 5. 环境与工具

- ArcGIS Pro：版本 __3.6.0__
- 工具：Spatial Analyst（栅格计算器、按掩膜提取）

## 6. 限制与后续

- 单景覆盖约 185 km，不足全省；完整省域需多景镶嵌（后续工作）
- 数据年份为 2021（平台数据更新滞后）
- 未做云掩膜（云量 _0.07_%，影响较小）
